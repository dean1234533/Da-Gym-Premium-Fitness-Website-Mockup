## Features

- A hero with a clear "join today" call to action
- **Membership plans** for every training style
- **Facilities** showcase and an **energetic class timetable**
- **Personal trainer** guidance section
- **Member stories** as social proof
- A location and contact section
- A fully responsive, mobile-first layout

## Tech stack

A single, self-contained `index.html` file of hand-written HTML, CSS, and
vanilla JavaScript. It has no frameworks and no build step.

## Run locally

```bash
git clone https://github.com/dean1234533/Da-Gym-Premium-Fitness-Website-Mockup.git
cd Da-Gym-Premium-Fitness-Website-Mockup
open index.html   # or double-click it
```
